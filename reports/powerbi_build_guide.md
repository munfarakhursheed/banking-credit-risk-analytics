# Power BI Build Guide
1. Import `borrowers.csv`, `loans.csv`, `loan_payments.csv`.
2. Create relationships: borrowers → loans → loan_payments.
3. Suggested measures:
   - Loan Count = COUNT(loans[loan_id])
   - Portfolio Exposure = SUM(loans[loan_amount])
   - Defaulted Loans = CALCULATE(COUNT(loans[loan_id]), loans[default_flag] = 1)
   - Default Rate = DIVIDE([Defaulted Loans],[Loan Count])
   - Average Loan = AVERAGE(loans[loan_amount])
   - Late Instalment Rate = AVERAGE(loan_payments[late_payment_flag])
4. Build pages: Portfolio Overview, Risk Segments, Payment Behaviour.
5. Add loan type, region and origination date slicers.
6. Treat all results as synthetic demonstration only; never use for real credit decisions.
Note: a `.pbix` file is not generated by this package; these are import-ready source files and build instructions.
